# 光储方案台

一个用于初步估算家庭光伏与储能配置的中文小工具。填写用电量、可用屋顶面积和当地发电条件，即可查看建议装机容量、组件数量、储能容量与粗略年度收益。

源码仓库：[Wang716-tim/solar-storage-planner](https://github.com/Wang716-tim/solar-storage-planner)。

> 本工具用于前期方案比较，不替代现场勘测、并网审查、电气设计或施工规范校核。计算依赖用户填写的估算参数。

## 快速开始

需要 Node.js 20 或更新版本，无需安装第三方依赖。

```bash
npm start
```

在浏览器打开终端显示的本地地址。运行测试：

```bash
npm test
```

## 当前功能

- 按年用电需求和屋顶面积估算光伏装机规模。
- 根据年等效发电量、白天用电比例和备用时长估算发电及储能。
- 展示自发自用、上网电量、年收益和静态回收期。
- 校验输入范围，并将采用的估算参数展示在结果旁。
- 在本机运行，不发送输入数据到服务器。

## 计算流程

```text
输入参数 → 范围校验 → 确定性估算 → 结果展示与假设说明
```

输入校验与计算位于 `src/engineering.js`，页面交互位于 `src/app.js`。估算逻辑可脱离界面单独运行和测试。

## 估算口径

当前版本采用用户输入的年等效发电量、组件功率与面积、白天用电比例、电价和设备单价作简化估算。储能使用固定往返效率假设。模型没有模拟逐时辐照、天气、遮挡、朝向、逆变器限功率、分时电价或电池衰减，因此结果用于比较假设，不是收益承诺。
