# 向阳 · 光储估算设计

## 目标

提供一个简体中文、本地运行的家庭光伏与储能初步估算工具。用户能调整用电与屋顶条件，并看见计算结果及关键假设。

## 用户流程

用户填写月用电量、白天用电比例、供电比例目标、屋顶面积、年等效发电量、备用时长、购电价、上网价和安装单价。页面校验后展示组件数、光伏容量、年发电量、建议电池容量、自用/上网电量、年节省和静态回收期。

## 架构

原生 HTML/CSS/ES Modules 页面通过纯函数调用计算模块；Node.js 内置 HTTP 服务只绑定回环地址并提供项目静态文件。测试使用 Node 内置测试运行器，无第三方运行时依赖。

## 边界与错误

输入范围通过字段配置定义，空值、非数字和越界值均返回中文字段错误。页面不展示过期或不完整结果作为新结果；计算异常作为输入问题呈现。静态服务将访问限制在项目目录。

## 验收标准

- 应用不依赖网络服务或密钥即可启动。
- 页面使用简体中文，并在桌面和窄屏保持可用。
- 工程数值只由确定性计算模块生成。
- 单元、边界、错误处理和 HTTP 集成测试通过。
- 结果明确标明简化假设和工程使用边界。
