# 产品说明

## 用户目标

用户希望用少量可获得的数据，了解屋顶光伏方案的大致容量、电量和费用区间。

## 使用流程

1. 输入月用电量、白天用电比例和供电目标。
2. 输入屋顶面积、年等效发电量与备用时长。
3. 输入购电价、上网价和光伏安装单价。
4. 查看组件数量、装机容量、年发电、建议储能和简单收益估算。
5. 展开说明，检查模型采用的主要假设。

## 用户界面约定

- 全部可见界面文案为简体中文。
- 默认参数仅用于演示交互，不代表任何具体住宅。
- 验证错误直接显示在对应输入下方。
- 结果需与输入和假设同时呈现。

## 功能边界

当前版本只做初步估算，不处理项目报价、并网审批、用电安全判断或施工方案。静态回收期不包含融资、维护、电池衰减、税费和价格变动。
