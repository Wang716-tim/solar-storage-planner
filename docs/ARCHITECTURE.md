# 架构说明

## 组件

| 模块 | 文件 | 责任 |
| --- | --- | --- |
| 产品页面 | `index.html` | 语义结构、输入表单、结果展示 |
| 页面样式 | `styles.css` | 布局、响应式样式、键盘焦点 |
| 工程核心 | `src/engineering.js` | 输入校验与确定性估算 |
| 页面控制器 | `src/app.js` | 读取表单、调用核心、更新显示 |
| 本地服务 | `server.js` | 仅绑定回环地址并提供静态文件 |
| 测试 | `tests/` | 核心边界与 HTTP 集成检查 |

## 数据流

```text
浏览器表单 → validateInputs → calculateScenario → 展示结果
                                 ↓
                           纯计算对象
```

`calculateScenario` 校验输入并返回计算结果；无效输入抛出包含字段错误的 `TypeError`。它不访问 DOM、网络或系统时钟，可以单独测试。

## 计算概述

- 年用电量 = 月用电量 × 12。
- 需求装机容量 = 年用电量 × 目标供电比例 ÷ 年等效发电量。
- 屋顶组件上限 = 向下取整（可用面积 ÷ 单块组件占地）。
- 实际组件数取满足需求的数量与屋顶上限中的较小值。
- 储能、直接自用、余电和静态回收期使用固定效率与用户输入电价估算。

公式常量集中在 `src/engineering.js`，界面在“计算说明”中公开关键假设。

## 安全与隐私

服务只绑定 `127.0.0.1`，不接收表单提交或写入用户数据；路径访问被限制在项目目录。所有表单计算在浏览器本地完成。

## 演进边界

如未来增加自然语言入口，它只能解析用户意图并调用受约束的计算工具；输入校验和确定性计算仍是结果依据。模型输出不得覆盖计算字段。
